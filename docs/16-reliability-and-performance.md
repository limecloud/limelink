# 可靠性、性能与观测

本文件列出设计目标和测量方法，不包含 LimeLink 实测数据。阈值是待 P1/P2 测量确认的候选，不影响上游已有的安全期限。

## 测量分段

每次任务记录 UI 明确提交、原请求落盘、网关受理、执行端收到、效果观察、结果可读取和 UI 展示的阶段时间。跨机器时钟未经校准不能直接相减；同一进程耗时使用单调时钟，跨机用关联 ID 和各段耗时解释。

| 指标 | 候选目标/规则 | 验证条件 |
| --- | --- | --- |
| 发送后的本地反馈 | 100 ms 内出现正在提交状态，目标值 | 目标设备 UI 测量，不等待网络 |
| 局域网卡片完成延迟 | P95 不超过 2 s，目标值 | 同网、端点前台、明确硬件/网关版本与负载 |
| 非前台/休眠电脑 | 明确不可用或结果待核实 | 不承诺唤醒或后台窗口观测 |
| 任务恢复 | 同一原键，零自动重复派发 | 丢响应/各进程重启故障注入 |
| 有界资源 | 所有输入、队列、任务和日志有上限 | 超限明确拒绝、无静默截断和无界增长 |

P95 样本数、测试时段、失败占比和设备条件必须同时记录。达不到目标时解释瓶颈，不只选最快请求作为演示。

## 连接与背压

客户端只保留每个关注对象必要的读任务，慢轮询单飞，较旧响应不能覆盖新事件或新空间状态。事件读取使用服务端游标；检测 gap 后查询当前对象，不编造缺失历史。

桌面接收端的队列、并发与输入字节上限在正式动作模型中固定，超限拒绝而不是排无限离线任务。语音/媒体和控制通道分别限制，控制线程不做长耗时解码或同步网络等待。

心跳、业务数据有效期和执行资格分开。连接心跳正常不证明窗口已显示、模型可用或本机权限仍存在。

## 失败模型

| 变化 | 行为 |
| --- | --- |
| 手机切网/后台 | 暂停页面读取，清核对，前台核实原请求 |
| 电脑休眠/退出 | 平台设备离线，新输入不默默转向其他电脑 |
| 网关重启 | 原账本恢复，重新认证/握手，旧执行不自动重发 |
| 控制面断线 | 远程新动作不可用；局域网能力按本地当前授权运行 |
| 本机磁盘满/记录损坏 | 禁止新提交，提供有限只读诊断与原任务核实 |

## 观测与保留

记录阶段、数量、耗时和错误分类，默认不存正文、录音或密钥。关联 ID 可用于本地排障，导出时提醒其可能包含设备/用户标识并允许检查。诊断和恢复记录使用不同保留策略，不能轮转掉仍未解决的操作证据。

TC-024 覆盖故障与负载，真实语音质量另按 TC-020 验收。
