# 需求基线与产品边界

本文件记录当前对话确认的方向。名称与仓库已确认；功能以目标设计表达，不表示已有可运行产品。

## 已确认方向

1. 产品名称 LimeLink，中文工作名“柠联”，独立仓库 `limecloud/limelink`。
2. 电脑上有独立桌面软件，技术架构参考 Shou 的原生客户端分层。
3. 手机端通过网关与电脑端建立授权协同关系，共同查看和操作允许的任务。
4. 通用平台能力复用 LimeIoT；仓库组织参考 Gootuan 的独立产品 monorepo。
5. 当前不与 Gootuan 产品功能集成。未来可参考 HachimoDock 的交互经验开发独立硬件终端。
6. 后续用户已将范围扩展到原生客户端与运行时实现、IoT 必要配合和完整文档/视觉/宣传站，并要求完成后提交 v0.1.0 Tag、推送 GitHub。当前已进入代码实施；版本放行仍须达到实际验收门槛。

## 规划假设

| 项目 | 当前建议 | 冻结前需要的证据 |
| --- | --- | --- |
| 首个开发目标 | macOS 14+ 桌面与已有 iOS 客户端 SDK 的联合切片 | 最小应用构建、网关连接和目标系统验证 |
| Windows | WinUI 3、.NET 10；单独交付与验收 | 原生构建、签名/安装、任务和后台进程检查 |
| 手机 | iOS 17+、Android API 26+ 的原生方案 | SDK 兼容、系统浏览器、前后台和安全存储验证 |
| 网关位置 | 已支持的 Linux/NAS 部署 | 精确镜像版本和已验收架构；不推定 Mac/Windows 原生可运行 |
| 首个协同任务 | 在目标电脑内展示一张用户明确发送的文本卡片 | 模型/路由、接收、显示与可查询回执的完整证据 |
| 内容保存 | 默认本地、有限保留，正文共享逐次明确选择 | 数据分类、期限、清除和备份策略测试 |

平台最低版本与工具链是待实现阶段确认的建议，不是当前支持承诺。移动端是否独立品牌发布、准确首发平台顺序、商业收费和上架地区见[未决事项](22-risks-and-open-decisions.md)。

## 首期范围

围绕单个空间、一个当前主网关、两类用户客户端和一个已授权桌面执行端，完成配对、能力发现、有界提交、结果查看和原任务恢复。局域网链路先验收，公网路径单独推进。

暂不纳入远程桌面画面传输、任意 Shell、全盘文件同步、任意第三方 App 操控、无人值守审批、插件市场、多主网关、硬件生产及跨端永久对话记忆。加入新范围必须更新 PRD、权限、数据和验收计划。
