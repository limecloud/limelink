# 术语与易混淆概念

| 术语 | 定义与边界 |
| --- | --- |
| 用户客户端 | 持用户会话、呈现任务并发起获准请求的 App |
| 执行端 | 持设备身份、接收特定动作并报告效果的运行时 |
| 终端 | 产品中可交互的入口或执行设备，具体角色必须另行标明 |
| 网关 | 拥有当前平台设备、授权、命令和规则事实的本地服务 |
| 控制面 | 管理云主体、绑定和受限远程入口的服务，不代替本地审批 |
| Space | 平台授权和设备范围；云与本地空间 ID 不一定相同 |
| Principal | 当前身份主体，不能由客户端自填名称证明 |
| 配对 | 建立受限关系的流程，须明确是用户登录、云绑定、设备接入还是产品协同 |
| 能力声明 | 实际运行端支持的类型化操作及预算，声明不自动授予权限 |
| 模型修订 | 平台物模型的精确版本/内容标识，与 AI 模型不是同一概念 |
| AI 模型 | 用于识别、生成或理解的提供方模型，配置存在不等于健康 |
| LinkSession | 目标设计中的产品协同会话，与设备通信 session 分开 |
| 路由修订 | 本次选择目标/输入端的条件更新版本，过期修订不能写入 |
| 原请求键 | 提交前固定并保存的幂等标识，查询旧键不生成新操作 |
| command_id | 平台原命令标识，客户端按不透明值使用 |
| accepted | 平台受理，不能证明执行端已产生效果 |
| submitted | 执行端报告输入已提交到目标系统，不表示已观察效果 |
| observed | 已报告并校验模型约定的观测范围，不能扩展解释为用户已读 |
| unknown | 无法确认结果，既不是失败也不是允许重复执行 |
| TTL/新鲜度 | 数据可以被当作当前状态的有效窗口，不产生动作授权 |
| 撤销 | 终止未来资格，不自动撤回已发生的系统副作用 |
| 取消 | 可能是草稿、等待或实际任务，界面必须写明取消对象 |
| 接续 | 转移允许的上下文与输入资格，不重启源任务 |
| 正式合同 | 版本化、实现与验证对应的机器/语义定义 |
| 候选设计 | 尚待接口冻结和实现的方案，不可作为运行 capability |
| 文档验证 | 文档结构和可追踪性检查，不等于产品验证 |

这些定义服务于本仓库解释。涉及平台正式状态和字段时，以 [LimeIoT 接入](12-gateway-integration.md)指向的当前上游合同为准。
