# 信息架构与交互规范

LimeLink 的界面围绕连接对象和任务，采用原生系统导航、权限弹窗和可访问控件。Shou 提供分层与原生交互参考，具体布局按 LimeLink 的任务设计。

## 桌面工作台

| 入口 | 主要信息与动作 |
| --- | --- |
| 工作台 | 当前网关/空间、选中协同端、最近任务、发送入口 |
| 终端 | 已批准电脑和手机的角色、最后观测时间、权限与撤销 |
| 会话 | 当前目标、可用输入方式、接续和正文共享范围 |
| 任务 | 原请求、阶段、完成范围、证据时间、核实与取消 |
| 内容 | 后续已支持的卡片/组件；未实现阶段不显示可用安装按钮 |
| 设置 | 网关、身份、隐私、系统权限、诊断、语言和更新 |

首次连接页解释需要现有网关，并提供明确地址输入。状态栏同时区分网关可达、当前用户已认证和桌面执行端已接入。右上角“在线”不能替代三个状态。

桌面卡片接收默认显示在 LimeLink 内部。系统通知是否允许、窗口是否实际可见和卡片是否被用户阅读是不同证据；“已读”只有独立产品机制与用户动作支持后才能出现。

## 手机入口

手机优先提供工作台、任务、终端和设置四个入口。配对相机按用户进入扫码页后申请；手动配对引用作为无相机条件下的替代。发送页保持目标可见，切换空间清除旧核对，关闭输入法后仍能看到提交结果。

手机的任务页从后台回来先读取原任务和当前权限，再恢复允许的操作。不能用缓存的在线标识直接开启控制。

## 状态文案

| 状态 | 推荐表达 | 不能推导的事 |
| --- | --- | --- |
| 网关受理 | 已受理 | 电脑已经显示 |
| 执行端已提交 | 输入已提交 | 目标应用已完成操作 |
| 效果观测成立 | 已显示 / 已完成已定义效果 | 用户已经阅读、所有外部系统完成 |
| 传输/结果不确定 | 结果待核实 | 执行失败或没有发生 |
| 端点数据过期 | 最近在线于…… | 当前可执行 |
| 已请求取消 | 正在请求停止 | 已停止或已撤回 |

颜色是辅助表达，图标和文字共同说明状态。错误给出可以执行的下一步，例如查询原任务、核对连接或重新登录，不提供会重复旧副作用的“一键重试”。

## 可访问性与国际化

遵循系统字体缩放、键盘焦点、VoiceOver/TalkBack 和减少动态效果设置；浅深色状态均可辨识。桌面最小窗口、手机窄屏、横屏、长名称及英文文案作为独立检查。共享语义 token、文案 ID 和状态含义，原生排版按平台适配，不强制四端像素相同。

当前已有跨端原生界面和独立视觉资源；macOS 本机窗口已验证部分旅程。多端可访问性仍按 TC-022 验收，资源来源和使用许可继续保留。
