## 本轮交付口径

本轮清单为 **28 张独立模型生成图**：两张探索、三张标志/角色/硬件母版、四张品牌应用、十一张软件/网关协同图和八张硬件生活场景。尺寸导出、SVG 追踪、缩略图和图册不重复计入生成图数量。

原始生成结果位于仓库的 [output/imagegen](../../output/imagegen/)，图册使用合成到白底的 WebP 预览，保留原始 PNG 的实际 alpha。可取用资源见 [assets](assets/)，固定色板见 [tokens.json](tokens.json)，生成清单见 [scene-plan.json](scene-plan.json)，实际结果见 [image-generation.json](image-generation.json)。

这里的屏幕均为设计效果图，硬件均为外观概念。可用图标资源不代表 App 已实现，场景图不代表硬件已制造、功能已验收或已经进入路线图承诺。
