字标固定拼写 **LimeLink**，两个 L 大写。中文工作名为“柠联”；没有独立定制的中文艺术字母版，不把任意生成字样当作中文标志。

字标 SVG 保留可编辑文本，采用 Arial / sans-serif 回退；本轮没有打包字体文件，也没有把文本转换为已校对的印刷轮廓。中文 UI 使用目标系统的无衬线字体。正式印刷或交付供应商前，选择有许可的字体、校对字距并转曲，单独保存最终文件。

## 固定色板

| 用途 | 色值 | 配合方式 |
| --- | --- | --- |
| 青柠主色 | #A8D85D | 角色、装饰、选中区域；避免白字 |
| 深林绿 | #263D2C | 正文、叶片、主要按钮 |
| 米白 | #F7F8EF | 浅色画布、深色按钮文字 |
| 成功 | #267047 | 配合勾形和状态文字 |
| 警告 | #8A4B00 | 配合时钟/警告图形和说明 |
| 错误 | #A52D36 | 配合错误图形及可执行的恢复说明 |
| 未知/离线 | #5D6572 | 问号、断连图形和文字，不能表示成功 |

深林绿与米白、深林绿与青柠可构成高对比组合。具体比值由交付检查记录计算；青柠与米白对比不足，不用于小字号文字或独立控件边界。语义状态始终同时使用文字和形状，不单靠绿色表达已观测。

数字 RGB 是本轮基准，不提供虚构的 Pantone、CMYK 或壳体色号。印刷、硅胶、喷涂、布料分别打样，目标色不能替代材料、工艺和照明下的实物验色。

## 尺寸、留白和背景

以可见角色高度 H 为尺度，周围至少保留 H/8 的净空，不包含外部文案和装饰。主标志建议最小高度 24 px；16 px 菜单/浏览器入口采用单色模板并在实际系统中检查，必要时仅保留轮廓。打印最小尺寸先以 8 mm 高度试样，再按工艺调整。

图标资源内部有平台用途所需的额外边距。不要先裁掉这些边距再套平台蒙版。照片背景优先放置实色底板；反白版不能直接放在局部明亮、纹理复杂的区域。

图标保留角色比例，文字和其他功能标记独立排版。角色表情可以表达欢迎、等待、完成、未知和隐私，但不以表情替代真实状态标签。

## 跨端视觉

macOS 使用带外部透明边距的圆角磁贴；iOS 的 1024 图标不预切圆角且完全不透明；Windows 同时提供透明 ICO 和独立 PNG；Android 提供独立前景、背景与单色层，由系统蒙版裁切。四端共用角色而保留原生交互规范。

深色界面使用深林绿/近黑画布、米白文字和受控青柠强调。减少动画系统设置启用时，角色静止，等待仍有明确文字；不以高频闪烁、持续摇晃或声音吸引注意。

## 禁用与交付检查

不横向压扁、不镜像叶片、不改成猫狗兔、不加复杂面部细节、不用低分辨率生成预览替代矢量。图标上不写平台名，不把成功勾永久烘焙到 App 标志，不以锁形装饰宣称未经核验的安全认证。

每次修改母版后重新导出并检查轮廓、双色、透明、反白、小尺寸、平台裁切、名称拼写及来源摘要。当前导出与检查记录见 [exports.json](exports.json) 和 [视觉验证](visual-verification.json)。
