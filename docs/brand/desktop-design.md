# 桌面界面与 3D 图标

桌面端定位为网关控制台，包含 Agent、设备与跨端协同。macOS 当前导航为概览、助手、设备、协同，网关与任务记录提供独立入口；协同内切换发送/接收。首页不展示协议、配置清单和教学段落，助手按实际配置提供操作。完整定位见[控制台与部署架构](../32-agent-console-architecture.md)。Windows 仍待同步该信息架构与目标系统验收。

## 页面与文案

| 页面 | 默认内容 | 按需展开 |
| --- | --- | --- |
| 概览 | 品牌插画、查找网关或管理设备、发送内容 | 无统计卡片或眉题 |
| 助手 | 本机待批准/执行任务、目标电脑、工作目录、文字输入和结果 | 配对核对码、错误详情；仅在必要时展示读取权限说明 |
| 设备 | 网关中实际读取的设备与在线状态 | 按工作空间读取，不把协同电脑当成全部设备 |
| 发送 | 选中电脑、编辑内容、语音输入、发送 | 配对核对码、共同编辑、保存内容 |
| 接收 | 查找网关、收到的内容、配对申请 | 管理员配置导入、已配对设备详情、诊断 |
| 网关 | 附近网关自动发现或账号登录 | 手动地址、首次访问密钥、连接详情；登录后选择工作空间 |
| 历史 | 当前结果、查询与归档 | 原始操作详情、取消尚未显示的内容 |

界面使用用户任务词汇。会话编号、版本、设备核对码只出现在相关操作中。原始回执留在操作详情；不通过文案或客户端缓存授予权限。局域网发现使用 Bonjour 和 NAS 公告器，不扫描端口；没有公告时显示真实空态。首次用户认证和电脑 MQTT 设备入网是不同流程，后者仍需管理员提供设备配置；二维码、自助入网和本机网关安装产品尚未实现。

## 视觉规则

[Radix 色表](../../assets/desktop/design/radix-colors.json)固定上游 `dbdb85470547c7d34b9001f48fddb08ded335979`，保留来源摘要和 [MIT 许可](../../assets/desktop/design/RADIX-LICENSE.txt)。Slate 用于背景、文字和边框；Teal 用于操作；Green、Amber、Red 表达成功、注意和失败。1–2 为背景、3–5 为交互表面、6–8 为边框和焦点、9–10 为实心操作、11–12 为文字。实心按钮单独检查文字对比度。

- 文字使用 12、14、22、36 四档，36 仅用于概览主标题，依靠字重和间距区分层级。
- 导航在各页面固定 72 高度；主按钮使用深青渐变、白色文字和图标，最低对比度 4.56。右上角齿轮与系统设置支持浅色、深色和跟随系统。
- 自定义线条为 0.5 逻辑单位。控件圆角 6，编辑区域圆角 10；列表使用留白和分隔线。
- 不使用装饰阴影、彩色边线、眉题和中点分隔符，没有持续动画和页面转场。
- 原生系统窗口、高对比模式与系统焦点遵循平台可访问性；品牌位图独立于界面语义色。
- 背景原图保留为交付素材，当前工作页面采用 Shou 风格的连续 Radix Teal/Slate/Blue 渐变，叠加低透明度 Mint/Blue/Violet 光斑；高对比模式省略光斑。

`python3 tools/generate-desktop-theme.py --check` 验证两端主题来自同一份色表。macOS 资源通过 SwiftPM 打包，Windows 使用同一份 PNG 的 Content 引用，运行时不请求图片服务。

## 配图和图标

![柠联 3D 应用图标](../../assets/desktop/images/icon.png)

桌面新增四张模型原图：欢迎插画、设备插画、柔和背景和 3D 应用图标。前三张使用用户指定的 flare / sunburst；图标使用 flare，结合原柠柠角色和用户提供的材质参考。它们与首批 28 张场景图分别登记，共 32 张独立模型原图。生成采用 imagegen 附带 CLI；完整提示词、请求模型、真实尺寸、alpha 范围、消费者和摘要见[桌面生成记录](desktop-generation.json)。

3D 图标保留柠柠的双圆轮廓、单片深绿叶、圆眼和笑脸；参考图只用于圆角磁贴、材质和厚度，不复制其角色。导出器移除磁贴外孤立像素，并保留主体原 alpha。当前桌面构建消费 [ICNS](../../assets/desktop/icons/LimeLink.icns) 与 [ICO](../../assets/desktop/icons/LimeLink.ico)。移动端需要符合各平台蒙版规则的独立导出，不能直接使用带预切圆角的桌面磁贴。
