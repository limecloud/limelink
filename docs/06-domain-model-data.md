# 领域对象与数据归属

当前代码与本文件目标设计的差异，以[实现与验证边界](29-implementation-and-verification.md)为准；未完成路径不构成可用承诺。

本文件定义产品概念和目标字段，尚不是可调用的 API 或最终数据库 Schema。运行字段必须以未来正式 Schema 和上游合同为准。

## 对象与关系

| 对象 | 作用 | 事实源 |
| --- | --- | --- |
| Principal | 登录主体与当前权限 | LimeIoT 当前认证系统 |
| Space | 设备和授权的空间边界 | LimeIoT；云/本地空间 ID 分别处理 |
| Gateway | 主网关机器身份、绑定与连接 | LimeIoT 配对及机器连接 |
| ClientInstallation | 某次客户端安装的标识和本机偏好 | 产品客户端；安装标识不能充当认证凭据 |
| DesktopEndpoint | 具备获准动作的桌面执行实例 | 平台 Device/物模型及本机身份 |
| CollaborationBinding | 用户选择的手机/电脑协同关系、修订和显示偏好 | LimeLink 产品元数据；执行资格仍由平台校验 |
| LinkSession | 输入路由、共享上下文和写入资格 | 目标设计；需明确网关承载接口后实施 |
| TaskReference | 产品旅程到原平台任务/命令的关联 | 平台任务为执行事实，产品仅保存引用 |
| LocalEffectRecord | 精确本机动作的意图、实际观察或未知结果 | 桌面执行端；上报平台原命令 |

客户端安装、桌面设备、网关机器和用户主体不共用一个 ID。应用重装不自动恢复旧设备执行权，电脑重命名也不改变固定设备身份。

## 候选数据边界

协同关系需要绑定精确 origin、空间、目标 device_id、产品绑定 revision、创建/撤销时间。权限列表用于展示获准范围，不能作为客户端自签授权。撤销后旧 revision 不得重新激活。

会话候选字段包含 session_id、route_revision、active_input_endpoint、共享正文范围及 expiry。网关里的平台 session_id 另指设备通信会话，两者不得混用。任务关联需要原请求键、内容摘要、原 command_id 和执行端身份。

ID 视为不透明值，界面不拆解平台 command_id 编码。时间采用明确 UTC 表达；新鲜度由服务端规则计算。客户端时钟不能延长配对、授权或任务期限。

## 状态投影

终端显示分开保存“最后观察时间”“当前可达”“授权有效”“能力可用”。用户 UI 的前台、执行端进程在线和电脑未休眠也分别观察。陈旧快照只能说明过去状态。

当前上游命令状态、完成范围与字段不在产品内另起同义枚举。产品展示层可将其映射为中文文案，但保留原值和已验证证据范围。

## 保存、迁移与清除

| 数据 | 默认策略 | 注意事项 |
| --- | --- | --- |
| 用户会话、设备私钥 | 系统安全存储，按身份分区 | 用户凭据与设备凭据分别撤销和轮换 |
| 未决原请求 | 可靠落盘、回读校验，保留至按正式策略收敛 | 不能为腾空间删除未知请求后换键发送 |
| 任务正文 | 尽量不进入产品恢复账本 | 需要敏感正文恢复时使用加密及明确保留政策 |
| UI 偏好 | 普通本机配置，显式格式版本 | 不能用于证明权限 |
| 共享上下文 | 初期有限内存、选择后传送 | 应用退出和后台清屏与任务恢复分离 |

数据库和本机文件不构成与系统副作用的原子事务。版本升级时进行只读检查、备份与显式迁移，旧记录无法无损解释时禁止新控制并提供核实路径。
